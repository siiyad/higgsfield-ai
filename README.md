# Higgsfield AI — AI-Native Creative Suite

A modern, high-performance replica of the Higgsfield AI web application. Features a comprehensive suite of creative AI tools including Studio, Audio, Canvas, Developer APIs, Agent Workspaces, and Community showcases.

## 🚀 Features

- **Studio**: AI image and video generation playground with model presets and customization controls.
- **Audio Suite**: Generative audio, voice cloning, and sound effects tools.
- **Canvas**: Interactive creative workspace for visual workflows.
- **Developer API**: Documentation and API playground for AI integrations.
- **Agent Workspace**: Autonomous creative agents and pipeline automation.
- **Community & Showcase**: Explore creations and workflows shared by the creator community.
- **Pricing & Plans**: Comprehensive pricing tiers and feature breakdowns.

## 🛠️ Tech Stack

- **Framework**: React 18
- **Build Tool**: Vite 6
- **Routing**: React Router 7
- **Icons**: Lucide React
- **Styles**: Custom CSS Design System with dark mode styling

## 📦 Getting Started

### Prerequisites

- Node.js (v18+ recommended)
- npm, pnpm, or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/siiyad/higgsfield-ai.git
cd higgsfield-ai

# Install dependencies
npm install

# Run the development server
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```

## 🌐 Deployment

Configured for one-click deployment on platforms like Vercel with SPA routing support (`vercel.json`).
