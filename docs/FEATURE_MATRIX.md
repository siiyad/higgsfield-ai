# Higgsfield AI Replica — Complete Feature & Architecture Matrix

## 1. Architecture Overview

- **Stack:** Pure client-side SPA built with `react` `^18.3.1`, `react-router-dom` `^7.1.5`, `lucide-react` `^0.469.0`, and `vite` `^6.0.7` (installed `6.4.6`) ([package.json](file:///c:/Users/mhd%20siyad/OneDrive/Desktop/PROJECTS/MY-AI-PROJECTS/higgsfield/package.json#L1-L21)).
- **Routing & Splitting:** Lazy code-split route architecture inside [`App`](file:///c:/Users/mhd%20siyad/OneDrive/Desktop/PROJECTS/MY-AI-PROJECTS/higgsfield/src/App.jsx#L98-L235) wrapped in a top-level [`ErrorBoundary`](file:///c:/Users/mhd%20siyad/OneDrive/Desktop/PROJECTS/MY-AI-PROJECTS/higgsfield/src/App.jsx#L22-L64) and React `<Suspense>` fallback, plus explicit 404 fallback via [`NotFoundPage`](file:///c:/Users/mhd%20siyad/OneDrive/Desktop/PROJECTS/MY-AI-PROJECTS/higgsfield/src/pages/NotFoundPage.jsx#L6-L49).
- **State Persistence & Constraints:** No backend API, server session, or external database exists in this repository. All persistent client state (`user`, `language`, `likedIds`, `savedGenerations`, `waitlistJoined`, `cookieConsent`) is schema-validated in [`AppProvider`](file:///c:/Users/mhd%20siyad/OneDrive/Desktop/PROJECTS/MY-AI-PROJECTS/higgsfield/src/context/AppContext.jsx#L145-L466) and persisted to `localStorage` under `hf_*` keys. AI generation runs, credit charges, waitlist signups, enterprise forms, and sandbox keys are **client-side stateful simulations** paired with static media catalogs and CDN assets (`static.higgsfield.ai`, `d8j0ntlcm91z4.cloudfront.net`, `images.higgs.ai`).
